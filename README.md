## Git Workflow

I follow these rules on every change, even though I'm the only developer:

1. Never commit directly to `main`.
2. Create a feature branch for each task: `feature/add-expense-form`, `fix/filter-bug`.
3. Make small, focused commits with clear messages (e.g. `Add ExpenseCard component`).
4. Open a pull request, review my own changes, then merge into `main`.
5. Delete the branch after merging.
